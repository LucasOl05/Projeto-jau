# School Hub Pro

Quero criar um ERP de gestão para uma escola de cursos profissionalizantes.

Antes de criar qualquer funcionalidade, quero que você siga uma metodologia segura de desenvolvimento.

Regras:

- Não altere funcionalidades existentes sem minha autorização.

- Antes de modificar estruturas importantes, informe quais tabelas, componentes ou permissões serão afetados.

- Sempre preserve dados existentes.

- Não remova campos ou tabelas sem confirmação.

- Crie alterações de forma incremental.

O sistema será desenvolvido por módulos.
